Data Security Plan (Summary)

This page provides a high-level summary of how Watson Advisory Services approaches data security, client communication, and document handling.

Security approach

  • Use of a professional tax software client portal for secure document exchange and signatures
  • Restricted access to client information and role-limited handling of records
  • Preference for portal-based document handling for tax workflows
  • Ongoing review of operational and data-handling practices

Client communication

New tax clients may begin with a quote request to avoid sending sensitive information right away. Once scope is confirmed, the portal can be used for documents, questions, and e-signatures.

Practical note

This is a public-facing summary, not the full internal security documentation. If you have questions about the portal or document handling, please ask directly.
